# idea

Raw R&D ideas for altr.lab.

## Workflow

```
idea (R&D)
  → feature_list          # turn ideas into actionable feature briefs
  → plan                  # plan using feature_list + tech_space
  → implement             # code in apps / cloud / elements
  → tech_space            # write implementation docs
  → report                # status sum-up (STATUS.md)
```

Also use:

- **clickup/** for task tracking while work is in flight
- **agents/** for AI sub-agent instructions / skills / prompts

Keep ideas messy and dated here; promote them intentionally — do not skip straight from idea to large code changes without a feature brief and plan.
