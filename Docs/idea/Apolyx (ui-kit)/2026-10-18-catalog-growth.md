> Open this for Apolyx ideas that are not in the promoted intent yet. Decided naming and the portable-kit brief stay in the earlier notes. Catalog: [[../2026-10-18-product-catalog]].

## What the catalog adds

The 2026-10-18 catalog treats Apolyx as the architecture showcase for every other altr.lab surface, with three growth bets:

| Bet | Meaning here | Already decided elsewhere? |
|-----|----------------|----------------------------|
| Public showcase | `@altr/hub` plus the docs app / Storybook as the front door for serious client work and one visual identity | Docs app and Storybook exist. A hub gallery of product shells is still an idea. |
| Token Studio | An in-house place to manage dark/light themes, brand colors, and motion | Token generation was asked in [[../2026-09-27-altr-lab-project-brief]] Track 1 and in the portable-kit note. A studio UI is not a closed sprint. |
| Premium layer | Sponsorship, consulting, paid themes | Hypothesis only. Not in feature_list. |

## Product phases for this residual

| Phase | Name | Outcome | Notes |
|-------|------|---------|-------|
| G1 | Showcase route | Hub or docs app page that shows one trading shell, one ledger shell, one card shell using the same tokens | Feeds Artemis, HyperFit, ForgeRealm without building those products |
| G2 | Token Studio slice | Edit a seed color and a motion duration, see the docs app update, export CSS variables | Aligns with the portable kit; promote into `feature_list/ui-kit/` when the export shape is chosen |
| G3 | Theme pack | One named premium theme (for example a trading dark with profit/loss colors) shipped as a token set | Monetization stays a hypothesis until G2 exports cleanly |

## When this growth is chosen

Add a sharpening note that picks G1 or G2, names the route, and lists non-goals (no new component sprint hidden inside the studio). Promote into the existing `feature_list/ui-kit/` track, not a second app folder.
