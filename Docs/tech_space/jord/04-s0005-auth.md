# Jord-S0005 — Studio S3 auth as-built

> Who: mimir / operators after S3. Plan: [[../../plan/Jord/Jord-S0005/README]] · Prior schema: [[03-s0004-schema]] · Intent: [[../../feature_list/Jord/03-jord-studio]].

## Contract

| Role | Read | Write records | ADD COLUMN |
|------|------|---------------|------------|
| `readonly` | yes | 403 | 403 |
| `editor` | yes | yes | 403 |
| `admin` | yes | yes | yes |

| HTTP | Meaning |
|------|---------|
| 401 | Missing / invalid bearer |
| 403 | Valid session, role insufficient |
| 409 | OCC (unchanged) |

`GET /health` stays public.

## Server (`cloud/jord`)

| Module | Role |
|--------|------|
| `src/auth/roles.ts` | Role union + capability helpers |
| `src/auth/token.ts` | Raw secret or HMAC session (`payload.sig`) |
| `src/auth/middleware.ts` | Hono auth + write/schema guards |
| `src/auth/config.ts` | `JORD_SERVER_TOKEN` / `JORD_DEFAULT_ROLE` |
| `src/load-env.ts` | Optional `.env` for local `pnpm dev:jord` |

Protected: `/records/*`, `/schema/*`. Bearer = raw `JORD_SERVER_TOKEN` (→ default role) **or** signed session token.

## Studio (`apps/jord-studio`)

| Piece | Behavior |
|-------|----------|
| `/login` | Password → HTTP-only `jord_session` cookie |
| Middleware | Redirect unsigned traffic to `/login` (unless `JORD_STUDIO_OPEN=1`) |
| `jord-proxy` | Attaches `Authorization: Bearer …` from session |
| UI gates | Insert / save / ADD COLUMN disabled for insufficient roles |
| `/help` | Session · role capabilities |

Env: see `apps/jord-studio/.env.example` and `cloud/jord/.env.example` (tokens must match).
