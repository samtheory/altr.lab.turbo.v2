# Jord-S0013 — blob buckets (as-built)

> Who: anyone extending Storage. Plan: [[../../plan/Jord/Jord-S0013/README]]. Prior: [[11-s0012-multi-table]].

## What shipped

| Layer | Change |
|-------|--------|
| `@altr/jord` | Table `jord_blobs`; port methods `listBlobBuckets` / `listBlobs` / `getBlobMeta` / `upsertBlobMeta` / `deleteBlobMeta`; name helpers `isValidBlobBucket` / `isValidBlobKey` |
| Disk | `data/blobs/<bucket>/<key…>` via `createBlobDiskStore` in `@altr/jord-server` (`JORD_BLOBS_ROOT` override) |
| `@altr/jord-server` | `/blobs/buckets`, `/blobs/:bucket`, `/blobs/:bucket/objects/:key` (GET/PUT/DELETE); write queue for meta+bytes; 10 MiB max; roles `canManageBlobs` / `canWriteBlobs` |
| Studio | Nav **Storage** → `/storage`; BFF `/api/blobs/*`; Apolyx-only UI |

## HTTP

| Method | Path | Role |
|--------|------|------|
| `GET` | `/blobs/buckets` | any authenticated |
| `POST` | `/blobs/buckets` `{ name }` | `admin` |
| `GET` | `/blobs/:bucket` | any authenticated |
| `PUT` | `/blobs/:bucket/objects/:key` | `editor`+ |
| `GET` | `/blobs/:bucket/objects/:key` | any authenticated |
| `DELETE` | `/blobs/:bucket/objects/:key` | `editor`+ |

`:key` is a single path segment (`encodeURIComponent` of the relative key).
