# Jord-S0001 — Slice 0 as-built

> Who: anyone wiring products to Jord, or mimir after Slice 0. Contract: [[../../feature_list/Jord/00-intent]] · Architecture: [[../../feature_list/Jord/02-architecture]] · Plan: [[../../plan/Jord/Jord-S0001/README]].

## Surfaces

| Package | Path | Role |
|---------|------|------|
| `@altr/jord` | `elements/jord` | `JordDriverPort`, `LibSqlAdapter`, Drizzle `records`, snapshot |
| `@altr/jord-server` | `cloud/jord` | Hono routes, serial write queue, WAL hygiene |
| DB file | `data/jord.db` | Gitignored; default `DATABASE_URL=file:./data/jord.db` |
| `@altr/base/db` | `elements/base/src/db` | Redirect stub only — use `@altr/jord` |

No Studio app, Postgres adapter runtime, Redis, Mongo, or sqlite-vec in this slice.

## Open path

1. `createJordClient({ url? })` resolves URL (`DATABASE_URL` or `file:./data/jord.db`)
2. Non-`file:` → `JordSlice0UrlError` (names Slice 0 limit)
3. `mkdir` parent of the file path
4. Pragmas: `WAL`, `busy_timeout = 5000`, `synchronous = NORMAL`
5. Idempotent `CREATE TABLE records` + `(bucket, created_at)` index (no drizzle-kit)

## OCC

- Insert: `crypto.randomUUID()`, `version = 1`, both timestamps = same `Date.now()` ms
- Update: `UPDATE … SET version = version + 1 … WHERE id = ? AND version = ?`
- Library result `{ ok: false, conflict: true }` → HTTP **409** on `PATCH /records/:id`

Timestamps are Drizzle `integer({ mode: "number" })` (64-bit-safe ms).

## Server

| Method | Path | Notes |
|--------|------|-------|
| `GET` | `/health` | `{ ok: true, dialect: "libsql" }` |
| `POST` | `/records` | Queued write |
| `GET` | `/records?bucket=` | Newest first |
| `GET` | `/records/:id` | 404 if missing |
| `PATCH` | `/records/:id` | Requires `version`; 409 on stale |

- Default port **8787** (`PORT` override)
- Write queue: in-process promise chain (`cloud/jord/src/queue.ts`)
- WAL: `PRAGMA wal_checkpoint(TRUNCATE)` every `JORD_WAL_CHECKPOINT_MS` (default 60s) and on `SIGINT` / `SIGTERM`

## Snapshot

`pnpm db:snapshot` → `@altr/jord` `snapshotDatabase` → SQLite `VACUUM INTO` under `data/snapshots/jord-<ts>.db`.
