# Template — structured note

Copy this when creating a durable note under `Docs/`.

```markdown
---
title: "Short human title"
description: "One-line purpose for search and agents"
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags:
  - folder-role
  - topic
---

# Short human title

> Who should open this and when.

## Context

…

## Details

…

## Links

- Related: [[…]]
- Code: `apps/…` / `cloud/…` / `elements/…`
```
