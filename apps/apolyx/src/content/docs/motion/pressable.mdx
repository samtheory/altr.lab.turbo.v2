## Usage

```tsx
<Pressable className="rounded-xl border p-4" onClick={open}>
  Open project
</Pressable>
```

Use it for custom clickable surfaces. `Button` already has its own press styles.

## Accessibility

Renders a native `<button>` (or your element via `asChild`). The scale effect is skipped under reduced motion.
