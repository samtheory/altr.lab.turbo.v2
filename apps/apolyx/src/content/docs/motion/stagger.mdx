## Usage

```tsx
<Stagger as="ul">
  {items.map((item) => (
    <StaggerItem key={item.id} as="li">
      {item.label}
    </StaggerItem>
  ))}
</Stagger>
```

## Accessibility

Under reduced motion items appear together with an opacity fade.
