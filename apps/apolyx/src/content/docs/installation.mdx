## Monorepo apps

Apps in altr.lab depend on the workspace package and import components directly.

```json
{
  "dependencies": {
    "@altr/apolyx": "workspace:*"
  }
}
```

Transpile the package and import the global stylesheet:

```ts
// next.config.ts
const nextConfig = { transpilePackages: ["@altr/apolyx"] };
```

```css
/* src/app/globals.css */
@import "@altr/apolyx/globals.css";
@source "../";
```

Wrap the root layout with the provider and the no-flash script:

```tsx
import { ApolyxProvider, ApolyxThemeScript } from "@altr/apolyx";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        <ApolyxThemeScript />
      </head>
      <body>
        <ApolyxProvider defaultTheme="default" defaultMode="system">
          {children}
        </ApolyxProvider>
      </body>
    </html>
  );
}
```

## Any other React app (CLI)

Requirements: React 19, Tailwind CSS v4, and a `@/*` path alias in `tsconfig.json`.

```bash
npx apolyx init
npx apolyx add button dialog line-chart
```

`init` writes `apolyx.json`, installs the `cn` utility and theme CSS, and adds the theme imports to your CSS entry. `add` resolves each item's dependencies, rewrites imports to your aliases, writes the files, and installs npm packages with your package manager.

<Callout title="Before the package is published" variant="warning">
  The `apolyx` package is private during Apolyx-S0001. Build it locally and point it at the registry:
  `pnpm --filter @altr/apolyx build && pnpm --filter apolyx build`, then run
  `node <repo>/elements/apolyx-cli/dist/index.js init --registry <repo>/elements/ui-kit/dist/r`.
</Callout>

If your CSS entry was generated by `create-next-app`, delete its starter `:root` color variables — they override the Apolyx palette.

## The cn utility

Every component merges classes with `cn` (clsx + tailwind-merge), installed as `@/lib/utils` by the CLI:

```tsx
import { cn } from "@/lib/utils";

<div className={cn("rounded-md p-4", isActive && "bg-accent")} />;
```
