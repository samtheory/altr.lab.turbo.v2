## Installation

<InstallTabs name="line-chart" exports="ChartContainer, LineChart, type ChartConfig" />

## Usage

```tsx
<ChartContainer config={config}>
  <LineChart data={data} x="month" series={["desktop", "mobile"]} curve="monotone" area />
</ChartContainer>
```

## Tokens used

`--chart-1` … `--chart-5` for series, `--chart-grid` for grid lines, `--chart-axis` for labels.

## Accessibility

Lines draw in with Motion; under reduced motion they appear immediately. Name the chart with `aria-label` on `ChartContainer`.
