## Installation

<InstallTabs name="bar-chart" exports="ChartContainer, BarChart, type ChartConfig" />

## Usage

```tsx
<ChartContainer config={config}>
  <BarChart data={data} x="quarter" series={["web", "api", "mobile"]} stacked />
</ChartContainer>
```

## Tokens used

`--chart-1` … `--chart-5` for series, `--chart-grid` and `--chart-axis` for the frame.

## Accessibility

Bars grow in with Motion; under reduced motion they render at full height. Name the chart with `aria-label` on `ChartContainer`.
