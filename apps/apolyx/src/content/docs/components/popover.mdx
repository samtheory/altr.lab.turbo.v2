## Usage

```tsx
<Popover>
  <PopoverTrigger asChild>
    <Button variant="outline">Open</Button>
  </PopoverTrigger>
  <PopoverContent>
    <PopoverTitle>Dimensions</PopoverTitle>
    <PopoverDescription>Set the size of the layer.</PopoverDescription>
  </PopoverContent>
</Popover>
```

Click opens by default. Pass `trigger="hover"` when the panel should open on hover and stay open while the pointer crosses the gap. Use `PopoverAnchor` when the panel should position against a different element than the trigger.

## Motion

`motion` on `PopoverContent` is `pop` (default), `slide`, or `fade`. The panel grows from the trigger edge — never from its own center, and never from `scale(0)`. Reduced motion always fades.

## When to use what

| Need | Use |
|------|-----|
| Short non-interactive hint | `Tooltip` |
| List of actions | `DropdownMenu` |
| Interactive panel (form, filter, preview) | `Popover` |
| Blocking work the page must wait on | `Dialog` / `AlertDialog` |
| Full-height edge panel | `Sheet` |

## Accessibility

- Content is a non-modal `role="dialog"` with `aria-modal="false"`.
- Focus moves into the panel on open and returns to the trigger on close.
- Escape and outside pointer dismiss; Tab past the last control closes the popover.
- Nested with Dialog: only the top `DismissableLayer` closes.
