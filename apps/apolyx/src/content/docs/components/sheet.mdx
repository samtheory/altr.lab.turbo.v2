## Usage

```tsx
<Sheet>
  <SheetTrigger asChild>
    <Button variant="outline">Open menu</Button>
  </SheetTrigger>
  <SheetContent side="left">
    <SheetHeader>
      <SheetTitle>Workspace</SheetTitle>
      <SheetDescription>Jump to a section.</SheetDescription>
    </SheetHeader>
    <NavList>…</NavList>
  </SheetContent>
</Sheet>
```

Use `side="left"` for a navigation sidebar and `side="right"` for detail or settings panels.

## Built from

Sheet shares Dialog's state, so it gets the same Portal, FocusScope, DismissableLayer, and scroll lock. The panel slides in from its edge on a spring; under reduced motion it only fades.

## Accessibility

- `role="dialog"` with `aria-modal`, labelled by `SheetTitle`.
- Focus is trapped while open and returns to the trigger on close.
- Escape and outside click close it. The built-in close button is labelled "Close".
