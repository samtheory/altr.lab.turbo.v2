## Usage

```tsx
<Avatar>
  <AvatarImage src={user.image} alt={user.name} />
  <AvatarFallback>{initials(user.name)}</AvatarFallback>
</Avatar>
```

## Anatomy

`Avatar` → `AvatarImage` + `AvatarFallback`. The fallback shows until the image loads, and stays if it fails.

## Accessibility

Always give `AvatarImage` an `alt`. If the avatar sits next to the person's name, use `alt=""` so the name is not read twice.
