## Usage

```tsx
<NavList>
  <NavListGroup label="Workspace">
    <NavListItem href="/" active><Home /> Overview</NavListItem>
    <NavListItem href="/team"><Users /> Team</NavListItem>
  </NavListGroup>
</NavList>
```

Use it inside a fixed aside for a persistent sidebar, or inside a [Sheet](/docs/components/sheet) for a mobile drawer.

## Accessibility

- Rendered as `<nav>`; each group is a list labelled by its heading.
- The active item uses `aria-current="page"` and shows a primary bar.
- Disabled items use `aria-disabled` and cannot be focused.
