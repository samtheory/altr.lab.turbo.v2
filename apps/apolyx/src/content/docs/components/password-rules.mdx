## Usage

```tsx
import { PasswordRules } from "@altr/apolyx";

<PasswordRules
  label="Choose a password"
  onValueChange={(value, score) => console.log(value, score)}
/>
```

Prefer composing `PasswordInput` + `PasswordStrength` inside a `Field` when you need a custom layout. `PasswordRules` is the ready-made signup surface with animated meter segments and checklist icons.

## Accessibility

The meter uses `role="meter"`. Checklist items expose met / not-met through screen-reader text. Motion respects `prefers-reduced-motion`.
