## Usage

```tsx
<DropdownMenu>
  <DropdownMenuTrigger asChild>
    <Button variant="outline">Options</Button>
  </DropdownMenuTrigger>
  <DropdownMenuContent align="end">
    <DropdownMenuItem onSelect={duplicate}>Duplicate</DropdownMenuItem>
    <DropdownMenuSeparator />
    <DropdownMenuItem onSelect={remove}>Delete</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

Call `event.preventDefault()` in `onSelect` to keep the menu open.

## Anatomy

`DropdownMenu` → `DropdownMenuTrigger` + `DropdownMenuContent` (`DropdownMenuLabel`, `DropdownMenuItem`, `DropdownMenuCheckboxItem`, `DropdownMenuRadioGroup` → `DropdownMenuRadioItem`, `DropdownMenuSeparator`, `DropdownMenuShortcut`).

## Accessibility

Follows the WAI-ARIA menu button pattern.

| Key | Action |
|---|---|
| Enter / Space / ArrowDown | Open and focus the first item |
| ArrowUp (on trigger) | Open and focus the last item |
| ArrowDown / ArrowUp | Move between items (wraps, skips disabled) |
| Home / End | First / last item |
| Letters | Typeahead to the next matching item |
| Enter / Space | Select the focused item |
| Escape / Tab | Close and return focus to the trigger |

Submenus are not part of this release.
