## Usage

```tsx
<AppSidebar defaultOpen>
  <AppSidebarHeader>
    <AppSidebarBrand>Apolyx</AppSidebarBrand>
    <AppSidebarToggle />
  </AppSidebarHeader>
  <AppSidebarBody>
    <AppSidebarItem href="/" active>Home</AppSidebarItem>
  </AppSidebarBody>
</AppSidebar>
```

Collapse with the toggle or **Ctrl/⌘+B**. Width animates; labels hide when collapsed. Controlled via `open` / `onOpenChange`.
