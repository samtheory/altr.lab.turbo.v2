## Usage

```tsx
import { AvatarStatus } from "@altr/apolyx";

<AvatarStatus status="online" fallback="ON" />
<AvatarStatus status="busy" src="/user.png" alt="Sam" pulse={false} />
```

Statuses: `online`, `offline`, `busy`, `away`. Online pulses unless `pulse={false}`.
