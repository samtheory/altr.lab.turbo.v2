## Usage

```tsx
<InputGroup>
  <InputGroupAddon>
    <Search />
  </InputGroupAddon>
  <InputGroupInput placeholder="Search" />
  <InputGroupAddon align="inline-end">
    <InputGroupButton>Go</InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```

The group owns the border, focus ring and invalid state; the input inside is borderless. Addon order in the markup does not matter — `align` decides where it sits. Clicking empty space in an addon focuses the input.

## Accessibility

- The group has `role="group"`; label the input itself (`aria-label`, `Label`, or `Field`).
- Addon text is decorative to screen readers unless you reference it with `aria-describedby`.
- Buttons inside are real buttons with `type="button"`, so they never submit the form by accident.
