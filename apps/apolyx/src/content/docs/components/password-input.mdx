## Usage

```tsx
<Field label="Password">
  <PasswordInput autoComplete="current-password" />
</Field>

<PasswordStrength value={password} variant="both" />
```

`PasswordInput` is an [Input Group](/docs/components/input-group) with a show / hide toggle. Inside a `Field` it uses the field's box; on its own it draws one.

## Basics

The toggle is a pressed / not-pressed button. Clicking it while typing keeps focus and the caret where they were. Pass extra addons as children.

## Strength

### Bar

One segment per rule. The colour moves from `destructive` to `warning` to `success`, and the level label is announced when it changes.

<ComponentPreview name="password-strength-demo" />

### Checklist

`variant="checklist"` lists each rule; `"both"` shows the bar too.

<ComponentPreview name="password-strength-checklist-demo" />

### Custom score

Pass `score` and `max` to plug in your own estimator (for example zxcvbn) without adding a dependency to the kit. `labels` renames the levels.

## Accessibility

- The toggle has `aria-label="Show password"`, `aria-pressed`, and `aria-controls` pointing at the input.
- Set `autoComplete` to `current-password` or `new-password` so password managers help.
- The strength bar is a `meter` with a text value; the level text is a polite live region.
