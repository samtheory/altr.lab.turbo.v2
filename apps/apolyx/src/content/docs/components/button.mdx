## Usage

```tsx
<Button variant="outline" size="sm" onClick={save}>
  Save
</Button>
```

Render a link that looks like a button with `asChild`:

```tsx
<Button asChild>
  <Link href="/docs">Read the docs</Link>
</Button>
```

## Variants

`default`, `secondary`, `outline`, `ghost`, `destructive`, `link`, `shiny`, `status`, and `status-inset`. Sizes: `xs`, `sm`, `md`, `lg`, `icon`, and `icon-xs`. Use `buttonVariants()` to style other elements the same way.

## Shiny

A click action with color drifting inside and a soft wave traveling the border. `shine="rainbow"` moves through violet, blue, green, amber, and rose. The other shines lock the wave to one hue: `iris`, `ocean`, `lime`, `amber`, `rose`. The motion is slow, and it stops under `prefers-reduced-motion`.

<ComponentPreview name="button-shiny-demo" />

```tsx
<Button variant="shiny">Generate</Button>
<Button variant="shiny" shine="ocean">Ocean</Button>
```

## Status

Two faces for the same tones: Pending, In progress, Submitted, In review, Success, Failed, Expired.

`status` is a tinted face with a matching icon and label. `status-inset` keeps that face color as an inner border (`--status-wash`, the filled button’s background) on a quieter fill.

<ComponentPreview name="button-status-demo" />

```tsx
<StatusButton tone="pending" />
<StatusButton tone="success" variant="status-inset" />
<Button variant="status" tone="review">Needs a look</Button>
```

## Tokens used

`primary`, `secondary`, `destructive`, `success`, `warning`, `info`, `muted-foreground`, `status-submitted`, `status-review`, `accent`, `input`, `ring`, `radius`.

## Accessibility

- Native `<button type="button">` by default; Enter and Space activate it.
- `loading` sets `aria-busy` and disables the button while showing a spinner.
- Icon-only buttons need an `aria-label`.
- Focus ring uses the `ring` token and is only shown for keyboard focus.
