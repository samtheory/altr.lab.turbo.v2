## Usage

Same shell as a button group. The action clicks through. The icon opens a menu that scales up from the button edge (`motion="expand"`), origin on the trigger side. Reduced motion fades it instead.

```tsx
<SplitButton>
  <SplitButtonAction onClick={save}>Save</SplitButtonAction>
  <SplitButtonMenu>
    <DropdownMenuItem>Save as draft</DropdownMenuItem>
    <DropdownMenuItem>Save and publish</DropdownMenuItem>
  </SplitButtonMenu>
</SplitButton>
```

Menu items are the dropdown menu parts. Arrow Down or Arrow Up on the icon opens the menu and moves focus into it.

## Accessibility

- The icon trigger is named with `label` (default `"More actions"`).
- It exposes `aria-haspopup="menu"` and `aria-expanded`.
- Choosing an item closes the menu and returns focus to the icon.
