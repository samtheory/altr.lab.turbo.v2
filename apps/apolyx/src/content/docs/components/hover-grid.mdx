## Usage

```tsx
<HoverGrid>
  <HoverGridItem index={0}>One</HoverGridItem>
  <HoverGridItem index={1}>Two</HoverGridItem>
</HoverGrid>
```

Hovering one cell highlights it and dims siblings via shared context.
