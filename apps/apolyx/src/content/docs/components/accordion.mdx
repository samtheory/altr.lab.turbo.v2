## Usage

```tsx
<Accordion type="single" collapsible defaultValue="schema">
  <AccordionItem value="schema">
    <AccordionTrigger>Schema</AccordionTrigger>
    <AccordionContent>Tables and columns.</AccordionContent>
  </AccordionItem>
</Accordion>
```

`type="multiple"` takes `string[]` for `value` / `defaultValue`. `Collapsible` is a single disclosure without grouping.

## Anatomy

`Accordion` → `AccordionItem` → `AccordionTrigger` + `AccordionContent`.
