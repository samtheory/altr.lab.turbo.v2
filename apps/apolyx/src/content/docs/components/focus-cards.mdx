## Usage

```tsx
<FocusCards
  items={[
    { title: "Alpha", description: "…", href: "#" },
    { title: "Beta" },
  ]}
/>
```

Pass `image` for optional thumbnails. Hover focuses one card and lowers opacity on the rest.
