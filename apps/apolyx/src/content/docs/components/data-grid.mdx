## Usage

```tsx
import { DataGrid, type DataGridColumnDef } from "@altr/apolyx"

type Row = { id: string; name: string; score: number }

const columns: DataGridColumnDef<Row>[] = [
  { id: "name", header: "Name", type: "text" },
  { id: "score", header: "Score", type: "number" },
]

<DataGrid
  columns={columns}
  rows={rows}
  getRowId={(row) => row.id}
  height={420}
/>
```

`DataGrid` owns column chrome (sort, hide, pin, resize, drag reorder), a typed filter builder, quick search, and a virtualized body. Filtering and sorting run client-side by default; pass `clientProcess={false}` when the parent already processed the rows.

Persist view state with the controlled `columnLayout`, `filters`, `sort`, and `quickSearch` props (and their `on*Change` counterparts). Call **Reset view** or write your own reset that restores `emptyColumnLayout(columnIds)`.

When the column set grows, `mergeColumnLayout` appends new ids without wiping widths, pins, or hidden state.

Row multi-select is opt-in: set `selectionMode="multi"` with controlled `selectedRowIds` / `onSelectedRowIdsChange`. The leading checkbox column includes select-all for the currently processed page; body rows are memoised so selection updates do not remount every cell.

## Accessibility

- Root uses `role="grid"` with `aria-rowcount` / `aria-colcount`.
- Headers expose `aria-sort`; the column menu is a standard `DropdownMenu`.
- Resize handles are `role="separator"` with an accessible name.
- Keyboard: focus the grid scrollport; header sort buttons and menus are tabbable.
