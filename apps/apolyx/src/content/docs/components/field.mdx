## Usage

```tsx
<Field label="Email" description="We never share it.">
  <FieldInput type="email" />
</Field>

<Field label="Bio" optional>
  <FieldTextarea />
  <FieldCounter max={160} />
</Field>
```

## Layouts

- **top** — label above the control.
- **floating** — label sits inside the control and shrinks onto the border while focused or filled.
- **inline** — label beside the control in a muted panel, separated by a border.

The default box is borderless: a soft muted pad that blooms a ring on focus. There is no bottom accent bar. Under reduced motion transitions are instant.

### Sizes and variants

`Field` takes the same `size`, `variant` and `shape` as `Input`, and passes them to its box.

<ComponentPreview name="field-variants-demo" />

## Label extras

`labelAside` puts content at the end of the label row: a link, a tooltip trigger or a badge. It is not part of the control's accessible name. `optional` adds a muted "(optional)" marker.

<ComponentPreview name="field-label-extras-demo" />

## Orientation

`orientation="horizontal"` puts the label and description in a left column. It responds to the field's own width (a container query), so it stacks again inside a narrow card. Set the column with `labelWidth`.

<ComponentPreview name="field-horizontal-demo" />

## Helpers and errors

### Character counter

`FieldCounter` reads the value length from the field. It turns amber near the limit, red and invalid past it, and announces politely only when close.

<ComponentPreview name="field-counter-demo" />

### Multiple errors

Pass an array to `error` to list every rule that failed. It is still one `role="alert"` region.

<ComponentPreview name="field-errors-demo" />

## Groups

Wrap related fields in `FieldSet` — a native `<fieldset>` with a legend and description.

<ComponentPreview name="field-fieldset-demo" />

Fields also host [Input Group](/docs/components/input-group) addons directly.

## Accessibility

- The label is a real `<label>` tied to the control by id.
- `description` and `error` are linked with `aria-describedby`; an error sets `aria-invalid` and is announced with `role="alert"`.
- `required` adds the native attribute and a visual marker.
