## Usage

```tsx
<Heading as="h2" size="md">Billing</Heading>
<Text tone="muted" size="sm">Invoices are sent on the 1st.</Text>
```

## Accessibility

Choose `as` for document structure and `size` for appearance — they are independent, so the outline stays correct.
