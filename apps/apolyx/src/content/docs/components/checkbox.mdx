## Usage

```tsx
<Checkbox id="terms" checked={accepted} onCheckedChange={(v) => setAccepted(v === true)} />
<Label htmlFor="terms">Accept terms</Label>
```

## Accessibility

- `role="checkbox"` with `aria-checked` of `true`, `false`, or `mixed` for indeterminate.
- Space toggles. Pair with a `Label` (or `aria-label`).
- Clicking an indeterminate checkbox makes it checked.
