## Usage

```tsx
<Grid cols={{ base: 1, sm: 2, lg: 4 }} gap="md">
  <Card>…</Card>
  <Card>…</Card>
</Grid>

<Grid minItemWidth="14rem">
  {items.map((item) => <Card key={item.id}>…</Card>)}
</Grid>
```

`minItemWidth` uses `auto-fill` + `minmax`, so columns adjust to the container without breakpoints.
