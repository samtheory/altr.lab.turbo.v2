## Usage

```tsx
<Combobox value={value} onValueChange={setValue}>
  <ComboboxTrigger placeholder="Search symbol" />
  <ComboboxContent>
    <ComboboxItem value="btc">BTC — Bitcoin</ComboboxItem>
    <ComboboxItem value="eth">ETH — Ethereum</ComboboxItem>
    <ComboboxEmpty>No symbol found</ComboboxEmpty>
  </ComboboxContent>
</Combobox>
```

## Anatomy

`Combobox` → `ComboboxTrigger` + `ComboboxContent` (filter input, `ComboboxItem`, `ComboboxEmpty`).

Studio Autocomplete layouts are **recipes** on this one component — not a second package.

## Accessibility

Combobox + listbox with a searchbox in the panel. Arrow keys move from the filter into options; Escape closes.
