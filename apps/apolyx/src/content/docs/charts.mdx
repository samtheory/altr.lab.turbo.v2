Apolyx charts are SVG drawn with React on [visx](https://airbnb.io/visx) scales and shapes — no canvas, no chart library runtime. Colors come from chart tokens, so they follow the active theme.

## ChartContainer

Measures its width, keeps an aspect ratio, maps your config to CSS variables, and handles loading and empty states. Every chart renders inside one.

```tsx
const config: ChartConfig = {
  revenue: { label: "Revenue", color: "chart-1" },
  cost: { label: "Cost", color: "chart-2" },
};

<ChartContainer config={config} aria-label="Revenue and cost by month">
  <LineChart data={data} x="month" series={["revenue", "cost"]} />
</ChartContainer>;
```

## Legend and tooltip

The legend toggles series on and off (buttons with `aria-pressed`). The tooltip follows the pointer and lists the values for the hovered point.

## Accessibility

Each chart is a labelled figure. Provide a meaningful `aria-label`, and for data that matters offer a table or summary next to the chart.
